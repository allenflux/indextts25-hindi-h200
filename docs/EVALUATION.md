小样本过拟合 gate：从 train split 取 16–64 条已人工听检的短语音，确保每 speaker 至少两条；留出独立 speaker 的少量验证材料。记录初始 loss 与固定样本生成；运行有限步数，观察 loss 是否稳定下降且训练样本发音/对齐改善。仅记忆训练样本并非泛化成功。若无明显改善、文本 token 异常、生成静音或重复，先查文本前端/标签/冻结参数/梯度，停止扩大数据。

100-step smoke gate：剔除 warmup 后记录 80 步稳定窗口，观察 BF16 loss、梯度、非零可训练参数与 checkpoint。吞吐和质量结果不可互相替代。通过后先增加一个小规模阶段；最终 test 集只用于选定方案的最终评估，不反复调参。

已知导出风险：参考后端 `train_heads=true` 会训练 `mel_head` 与 `text_head`；其 adapter 导出逻辑未包含 `text_head`。配置故意保留这一实验路线，但**发布被导出一致性 gate 阻塞**，直到修改后的有许可后端能完整保存/加载，或证据证明实际输出所需参数被一致恢复。不得把当前导出的 adapter 宣称为完全复现训练状态。

发布前还需：数据与模型许可审核、明确非官方声明、锁定原始权重和全部依赖哈希、重建步骤、至少一次干净环境加载、Hindi/旧语言评测记录、已知失效范围。adapter 按语言分目录和版本；保留原始权重只读副本，回滚只需停用该语言 adapter。并发推理的不同 adapter 使用隔离进程/模型实例，禁止未验证的共享状态动态切换。
